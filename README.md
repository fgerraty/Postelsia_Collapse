# Postelsia Collapse

*Short synopsis*

------------------------------------------------------------------------

There are X R scripts associated with this repository run all console and data preparation, data cleaning, analysis, and visualization steps:

-   **00_Packages.R** loads every package that is needed in following scripts. After running this script, all following scripts can be run independently.

-   **01_Postelsia_Summary.R** cleans and summarizes *Postelsia palmiformis* transect data files.

------------------------------------------------------------------------
